# Protocolo de registro de ocorrências — Cenário 01

## 1 Objetivo

Este procedimento mostra como registrar os táxons dos papeis no sistema.
O bolsista registra os três papeis da amostra A-17.
Registre todos os papeis antes de revisar e salvar.

## 2 Itens necessários

- um computador com navegador de internet
- o sistema aberto no navegador
- os arquivos da pasta `papeis` (neste diretório)

## 3 Termos

| Termo       | Definição                                                                           |
| ----------- | ----------------------------------------------------------------------------------- |
| amostra     | conjunto de ocorrências de uma estação, em um dia                                   |
| coordenadas | posição da estação, em graus e minutos, sul e oeste                                 |
| data        | dia, mês e ano, no formato `dd/mm/aaaa`                                             |
| estação     | local onde se coleta a amostra                                                      |
| ocorrência  | quantidade de indivíduos de um táxon em uma amostra                                 |
| papel       | arquivo `papeis/papel_<n>.md` com a lista de táxons e as quantidades de um bolsista |
| táxon       | nome de um organismo                                                                |

## 4 Papeis

Use os três papeis da pasta `papeis`.
Os três papeis pertencem a mesma amostra (A-17).

| Amostra | Estação                                                | Papeis                                                        |
| ------- | ------------------------------------------------------ | ------------------------------------------------------------- |
| A-17    | Estação 1 – Parque Estadual do Boguaçu, Guaratuba (PR) | `papeis/papel_1.md`, `papeis/papel_2.md`, `papeis/papel_3.md` |

## 5 Tarefas

### 5.1 Abrir o cenário e confirmar a amostra

Objetivo: o sistema mostra a amostra dos papeis.

1. Abra o Cenário 01 no sistema.
2. Abra os três papeis.
3. Confira o número, a data, a estação e as coordenadas da amostra no sistema.

### 5.2 Registrar as ocorrências

Objetivo: o sistema tem cada linha da tabela de todos os papeis.

1. Para cada linha da tabela, registre o táxon e a quantidade no sistema.
2. Registre todas as linhas do papel.
3. Repita para cada um dos três papeis.
4. Vá para a próxima etapa.

### 5.3 Revisar as contagens

Objetivo: a quantidade de cada táxon confere com a soma dos papeis.

1. O sistema soma as quantidades de um mesmo táxon.
2. Para cada táxon, some as quantidades dos três papeis.
3. Compare a soma com a quantidade que o sistema exibe.
4. Se uma quantidade estiver errada, corrija o valor.

### 5.4 Confirmar o resumo e salvar

Objetivo: a amostra fica salva no sistema.

1. Confira o resumo da amostra.
2. Compare cada valor com a soma dos três papeis.
3. Se um valor estiver errado, volte para a revisão das contagens e corrija o valor.
4. Confirme o resumo.
5. Salve a amostra.

## 6 Se ocorrer um erro

- Se a última entrada estiver errada, desfaz a entrada e registre a quantidade certa.
- Se um erro aparecer depois da revisão, corrija o valor na revisão das contagens.

## 7 Critérios de conclusão

A tarefa está completa quando:

1. todas as linhas dos três papeis estão registradas
2. a quantidade de cada táxon confere com a soma dos três papeis
3. o sistema mostra a amostra como salva
